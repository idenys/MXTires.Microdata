# MXTires.Microdata release notes
##Release v. 1.0.4.8
<i>Thing.SubjectOf</i> validator now accepts <i>Event</i> in addition to <i>CreativeWork</i>, matching schema.org's <i>CreativeWork | Event</i> union. Fixed <i>IBook.Isbn</i>/<i>Audiobook.Isbn</i> type mismatch (now <i>string</i>, matching <i>Book.Isbn</i>). Added <i>Thing.Owner</i> (<i>Organization</i> or <i>Person</i>), matching schema.org. Added <i>Action.ActionProcess</i> (<i>HowTo</i>) and <i>Action.Provider</i> (<i>Organization</i> or <i>Person</i>); <i>Action.Location</i> now also accepts Text and <i>VirtualLocation</i>. <i>CreativeWork</i> now models 47 additional schema.org properties (<i>abstract</i>, <i>accessMode</i>, <i>funder</i>, <i>funding</i>, <i>isAccessibleForFree</i>, <i>isBasedOn</i>, <i>size</i>, <i>spatial</i>, <i>thumbnail</i>, <i>wordCount</i>, and more); added new <i>Grant</i> and <i>InteractionCounter</i> types. <i>Organization</i> now models 35 additional schema.org properties (<i>acceptedPaymentMethod</i>, <i>areaServed</i>, <i>hasCertification</i>, <i>hasCredential</i>, <i>hasMemberProgram</i>, <i>knowsAbout</i>, <i>numberOfEmployees</i>, <i>parentOrganization</i>, <i>sponsor</i>, and more); added new <i>Certification</i>, <i>Credential</i>, <i>MemberProgram</i>, and <i>ShippingService</i> types. <i>Place</i> now models 25 additional schema.org properties (<i>amenityFeature</i>, <i>containedInPlace</i>, <i>containsPlace</i>, the <i>geoContains</i>/<i>geoWithin</i>/etc. topology relations, <i>hasCertification</i>, <i>latitude</i>, <i>longitude</i>, <i>maximumAttendeeCapacity</i>, <i>slogan</i>, <i>smokingAllowed</i>, <i>tourBookingPage</i>, and more). <i>Product</i> now models 26 additional schema.org properties (<i>asin</i>, <i>colorSwatch</i>, <i>countryOfOrigin</i>, <i>funding</i>, <i>gtin</i>, <i>hasCertification</i>, <i>isFamilyFriendly</i>, <i>isVariantOf</i>, <i>keywords</i>, <i>material</i>, <i>size</i>, <i>slogan</i>, and more). Removed 9 redundant property overrides now inherited from the base classes above (<i>MediaObject.EncodingFormat</i>/<i>InterpretedAsClaim</i>, <i>Article.WordCount</i>, <i>EducationalOrganization.Alumni</i>, <i>VideoObject.Thumbnail</i>, <i>ImageObject.Thumbnail</i>, <i>Episode.IsAccessibleForFree</i>, <i>TVSeason</i>/<i>TVSeries.CountryOfOrigin</i>). <i>Offer</i> now models 14 additional schema.org properties (<i>additionalProperty</i>, <i>aggregateRating</i>, <i>areaServed</i>, <i>gtin</i>, <i>hasMeasurement</i>, <i>isFamilyFriendly</i>, <i>leaseLength</i>, <i>offeredBy</i>, <i>validForMemberTier</i>, and more). <i>Person</i> now models 14 additional schema.org properties (<i>agentInteractionStatistic</i>, <i>callSign</i>, <i>children</i>, <i>funding</i>, <i>hasCertification</i>, <i>hasCredential</i>, <i>hasOccupation</i>, <i>interactionStatistic</i>, <i>knowsAbout</i>, <i>knowsLanguage</i>, <i>lifeEvent</i>, <i>pronouns</i>, <i>publishingPrinciples</i>, <i>skills</i>); added new <i>Occupation</i> type. Fixed <i>Person.Address</i> (was incorrectly typed <i>Organization</i>, now <i>PostalAddress</i>). Fixed two copy-paste bugs where <i>Person.Height</i>'s getter returned <i>WorkLocation</i> and <i>Person.Sponsor</i>'s getter/setter read/wrote <i>HomeLocation</i> instead of their own backing fields. Closed remaining schema.org property gaps across the rest of the library (<i>JobPosting</i>, <i>Accommodation</i>, <i>MedicalEntity</i>, <i>BroadcastService</i>, <i>Review</i>, <i>MusicGroup</i>, <i>LoanOrCredit</i>, <i>Event</i>, <i>Course</i>, <i>Certification</i>, and more) found by the same systematic diff. Fixed three real <i>Vehicle</i> bugs: <i>NumberOfAirbags</i> and <i>VehicleSeatingCapacity</i> serialized under wrong-cased/legacy JSON keys, and <i>VehicleIdentificationNumber</i> serialized under the wrong key entirely ("VehicleEngine", a copy-paste error) - all now serialize correctly. Continued closing gaps in <i>NewsArticle</i>, <i>MedicalTest</i>, <i>TVSeries</i>, <i>SoftwareApplication</i>, <i>PaymentCard</i>, <i>MemberProgramTier</i>, <i>EngineSpecification</i>, <i>Diet</i>, <i>Demand</i>, and <i>ApartmentComplex</i>. Continued closing gaps in <i>UnitPriceSpecification</i>, <i>Rating</i>, <i>OfferShippingDetails</i>, <i>Occupation</i>, <i>MedicalOrganization</i>, <i>MediaObject</i>, <i>GeoShape</i>, <i>GeoCoordinates</i>, <i>EducationEvent</i>, <i>CourseInstance</i>, <i>WebPageElement</i>, <i>VisualArtwork</i>, <i>TVSeason</i>, <i>SportsEvent</i>, <i>SingleFamilyResidence</i>, <i>Residence</i>, <i>Question</i>, <i>ProgramMembership</i>, <i>Physician</i>, <i>MerchantReturnPolicy</i>, <i>InteractionCounter</i>, <i>Credential</i>, <i>BuyAction</i>, <i>Blog</i>, <i>AudioObject</i>, and <i>Article</i>. Fixed four more real bugs found along the way: <i>CourseInstance.CourseMode</i> serialized under the wrong key ("coursePrerequisites"); <i>OrderItem</i> had three different properties (<i>OrderItemNumber</i>, <i>OrderItemStatus</i>, <i>OrderQuantity</i>) all serializing under the same "orderItemNumber" key; <i>Blog.BlogPost</i> was missing its <i>JsonProperty</i> attribute entirely; and <i>Order</i>/<i>OrderItem</i>'s <i>OrderStatus</i> enum serialized as a number instead of its name. Also upgraded <i>MedicalOrganization.MedicalSpecialty</i> from <i>string</i> to the proper <i>MedicalSpecialty</i> enum (matching <i>MedicalClinic</i>'s existing pattern), removing the need for duplicate overrides in <i>MedicalClinic</i>, and removed 5 more redundant property overrides (<i>Apartment</i>/<i>HotelRoom</i>/<i>Suite.Occupancy</i>, <i>HotelRoom</i>/<i>Suite.Bed</i>) now inherited from <i>Accommodation</i>.

##Release v. 1.0.4.7
Added net10.0 target framework. Fixed duplicate <i>identifier</i> serialization on <i>JobPosting</i>. <i>PriceSpecification.MembershipPointsEarned</i> now accepts a Number (any numeric type) or <i>QuantitativeValue</i>, matching schema.org. <i>TypeValidator</i> now checks type assignability instead of exact type equality, so list-typed union properties (e.g. <i>Offer.PriceSpecification</i>) correctly accept concrete list implementations like <i>List&lt;T&gt;</i>.
